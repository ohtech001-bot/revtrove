# Revtrove

متجر احترافي لمنتجات السيارات المطبوعة ثلاثية الأبعاد، مبني بـ React وNode.js وMySQL، ويدعم العربية والإنجليزية والعبرية.

## الوظائف

- متجر متجاوب مع RTL/LTR وثلاث لغات.
- عارض GLB تفاعلي 360° وتلوين مستقل لكل جزء.
- نص مخصص للقاعدة والكاليبر يظهر في المعاينة.
- طلب عادي ببيانات الزبون والتوصيل والملاحظات.
- طلب خاص مع رفع صورة ووصف القطع وألوانها.
- لوحة إدارة محمية لتصفية الطلبات والبحث عنها، تحديث الحالة والسعر والمدة، الطباعة، وإضافة منتجات.
- إنشاء ورقة طلب HTML تلقائيًا في `print-queue`، مع دعم إرسالها إلى برنامج طباعة محلي عند تفعيل الإعداد.

## التشغيل المحلي

1. نفّذ `npm install` لتثبيت الحزم.
2. انسخ `.env.example` إلى `.env` وغيّر `JWT_SECRET` وبيانات الإدارة وقاعدة البيانات.
3. شغّل MySQL 8 محليًا أو نفّذ `docker compose up -d mysql`.
4. نفّذ `npm run db:init` مرة واحدة لإنشاء الجداول والمنتجات الأولية.
5. شغّل `npm run dev` للتطوير، أو `npm run build` ثم `npm start` للإنتاج.

واجهة المتجر: `http://localhost:5173` أثناء التطوير. لوحة الإدارة: `/admin`.

## تفعيل خريطة موقع التوصيل

1. فعّل **Maps JavaScript API** و**Places API** في Google Cloud.
2. انسخ `client/.env.example` إلى `client/.env`.
3. ضع مفتاح المتصفح في `VITE_GOOGLE_MAPS_API_KEY` ثم أعد تشغيل الموقع.
4. لحماية المفتاح، قيّده بنطاقات الموقع عبر HTTP referrers واسمح فقط بواجهات Google المطلوبة.

تحديد الموقع الحالي يعمل على `localhost` أو عبر اتصال HTTPS. عند غياب المفتاح يبقى إدخال عنوان التوصيل اليدوي متاحاً.

## الطباعة التلقائية في المحل

الطلب يُنشئ ورقة جاهزة للطباعة تلقائيًا. للطباعة الصامتة من جهاز المحل، اجعل `AUTO_PRINT_ENABLED=true` واضبط `PRINT_COMMAND` كمصفوفة JSON تحتوي برنامج الطباعة ومعاملاته. مثال عام:

```env
PRINT_COMMAND=["C:\\Path\\To\\PrintTool.exe","--silent"]
```

يُمرَّر مسار ورقة الطلب كآخر معامل. يجب تقييد صلاحيات حساب الخدمة والطابعة، وعدم تشغيل أمر يعتمد على shell.

## الأمان قبل النشر

- استخدم HTTPS وشهادة صالحة، وسر JWT عشوائيًا لا يقل عن 32 حرفًا.
- غيّر كلمة مرور المدير الافتراضية، وأنشئ مستخدم MySQL بصلاحيات قاعدة Revtrove فقط.
- ضع الخادم خلف reverse proxy، فعّل النسخ الاحتياطي، ولا تعرض منفذ MySQL للإنترنت.
- راقب السجلات وحدّث الحزم دوريًا. المشروع يستخدم validation، rate limiting، Helmet، كلمات مرور مشفرة، استعلامات parameterized، وحدودًا صارمة للرفع.
